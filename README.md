# Coffee Point

Одностраничный сайт кофейни на React + Vite. Опубликован на GitHub Pages:
https://yasinkka07.github.io/coffee-point/

Разделы: шапка с навигацией, главный экран, о нас, меню, галерея, отзывы, контакты с формой бронирования.

## Команды

```bash
npm install      # установить зависимости
npm run dev      # запустить локально
npm run deploy   # собрать и опубликовать на GitHub Pages (ветка gh-pages)
```
